# LogicBox Prompt Contract

An AI extractor must return one complete Shen `source` artifact. Return no
Markdown fence, commentary, JSON, or partial fact list.

```shen
(set *logicbox-artifact*
  [logicbox-artifact
    [kind source]
    [protocol logicbox-artifact-v1]
    [schema schema-v1]
    [payload
      [
        [current-schema schema-v1]
        [term p1 plan]
        [term c1 claim]
        [plan p1]
        [plan-claim p1 c1]
        [claim c1 causal source target]
        [modality c1 possible]
        [scope c1 conditional]
      ]]])
```

## Rules

- Preserve uncertainty with values such as `unknown`, `possible`, and
  `contested`. Do not guess.
- Emit source facts only. Do not emit diagnostics or derived findings such as
  `fact-type-error`, `missing-context`, or `plan-status`.
- Use quoted Shen strings for natural-language content when the predicate
  accepts text.
- Keep predicate arity, ID classes, enums, and namespaces consistent with the
  contract emitted by `logicbox contract --output contract.shen`.
- Do not include adapter or report predicates unless a separate task explicitly
  requests them.
- Never repair malformed output outside Shen. The exact AI output is passed to
  `logicbox schema`; Shen accepts it or emits/reports the failure.

## Common Predicates

```text
[term Symbol TermKind]
[current-schema SchemaVersionId]
[plan PlanId]
[plan-claim PlanId ClaimId]
[plan-ground PlanId GroundId]
[plan-conclusion PlanId ClaimId]
[claim ClaimId RelationKind EntityId EntityId]
[modality AnyId Modality]
[scope AnyId Scope]
[context-known EntityId KnowledgeState]
[ground-claim GroundId EntityId EntityId]
[infers-to GroundId ClaimId]
[supports EntityId ClaimId]
[mechanism ClaimId EntityId]
[rewrite RewriteId ClaimId ClaimId]
[rewrite-claim RewriteId RelationKind EntityId EntityId]
```

The authoritative, complete registry is generated by Shen:

```sh
logicbox contract --output contract.shen
```

## Controlled Values

```text
Modality: asserted, probable, possible, hypothetical, contested, certain, unknown
Scope: local, global, bounded, comparative, section, document, conditional, universal, unknown
KnowledgeState: known, unknown, mixed, shown, provided, present
LifecycleState: proposed, accepted, superseded, withdrawn
```

## Invalid Output

These examples must be rejected by Shen rather than repaired elsewhere:

```shen
[ground-claim g1 source]
[scope c1 maybe-globalish]
[mechanism p1 m1]
[mystical-link c1 c2]
```
